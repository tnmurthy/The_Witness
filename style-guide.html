Foundations

Color palette

Navy carries editorial authority. Gold is a reserved signal accent — AI-generated content, the active nav item, required fields, the Wisdom Engine — kept meaningful by never becoming a default UI color. Neutrals are a cool paper tone, deliberately not warm cream.

Foundations

Typography

Three families, each with one job. Source Serif 4 is the editorial voice — headlines, hero stories, Wisdom Engine quotes. IBM Plex Sans runs the interface. IBM Plex Mono carries data, timestamps, and code. Weights stop at 600 — nothing heavier — to keep the "calm, minimal" reading experience the platform is built around.

Icons

lucide-react (already the platform's available icon library per the Solution Architecture tech stack). Stroke width 1.75 — slightly thinner than lucide's 2px default — for a more refined, editorial line weight. 20px is the standard UI size; 16px in dense contexts like data tables; 24px only for empty-state or feature illustrations.

Tables

Hairline row dividers rather than zebra striping (Linear-style flat density). Numeric columns are right-aligned in the monospace family for scannability. Header labels are uppercase and muted so they recede behind the data.

Guidelines

Accessibility

Target: WCAG 2.1 AA, per the Solution Architecture non-functional requirements. Every pair below was computed with the actual relative-luminance formula against the token hex values — not estimated.

Verified contrast ratios
PairRatioNormal text (4.5:1)Large text / UI (3:1)
navy-800 on white — primary button, body links11.26:1PassPass
neutral-600 on white — text-secondary7.59:1PassPass
white on navy-800 — button/sidebar text11.26:1PassPass
gold-600 on white — initial choice, failed2.94:1FailFail
gold-700 on white — corrected signal text/border/focus5.27:1PassPass
gold-900 on gold-100 — Today's Wisdom card text9.90:1PassPass
success/warning/danger/info-700 on their -100 bg5.9–8.1:1PassPass
neutral-200/300 hairline borders on white1.4–2.0:1Below 3:1 — see note

Known trade-off: hairline borders (--border-default, --border-strong) fall below the strict 3:1 non-text contrast minimum, the same characteristic shadcn/Radix's own default theme has. Mitigation: no input or control relies on its border alone — every field pairs a visible label, a background-fill step from the page, and a compliant 3:1+ focus ring (gold-700, 5.27:1) on interaction.

Other requirements
Focus visibilityNever removed. 2px offset + 4px gold-700 ring on every interactive element, keyboard and pointer alike.
Touch targetsMinimum 44×44px hit area, including icon-only buttons (40px visual + padding).
Color independenceStatus is never color-only — every badge pairs color with a text label; every chart series pairs color with a direct label or pattern.
Keyboard operabilityIssue Builder block reordering has an arrow-key alternative to drag-and-drop (Implementation Plan Milestone 4 risk item).
Motionprefers-reduced-motion respected; transitions capped at 240ms and disabled entirely when set.
Live regionsAI job status changes (Realtime-driven) announce via aria-live="polite", not color/animation alone.
Semantic structureLandmark regions (nav, main, aside), one h1 per view, heading order never skipped for visual sizing alone.
